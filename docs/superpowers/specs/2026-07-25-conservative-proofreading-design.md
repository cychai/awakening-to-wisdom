# 《醒与悟》五册保守校稿设计

## 目标

以李牧之作品《醒与悟》五册 PDF 原页为唯一校对依据，对现有 GitBook 书稿进行全量校阅。只修正可以从原页明确确认的文字与排版问题，增强阅读连贯性，不改变、删减、弱化或评价作者观点。

## 修订边界

允许修改：

- 明确的 OCR 误识别字、漏字、多字和乱码；
- 因 PDF 文本层造成的错误断行、跨页断句和段落粘连；
- 中文标点、引号、括号及标点前后的异常空格；
- 标题层级、标题断裂、目录标题与正文标题不一致；
- 数字、英文与中文之间因识别产生的异常拆分；
- 列表、问答、署名、日期及独立短句的版式；
- 页码、重复页眉页脚等不属于正文的排版噪声。

禁止修改：

- 作者观点、论证、语气、用词风格和价值判断；
- 可能引起争议、带有强烈立场或未经证实的原文表述；
- 事实内容、案例、人物及结论；
- 原文中的口语、粗俗表达或修辞，除非原页能明确证明当前文字属于 OCR 错误；
- 任何不能由原 PDF 页面确认的疑似错字。

## 两轮校阅

### 第一轮：资深校稿员

逐册检查标题、正文、问答、列表和分页衔接。第 1、2、5 册以原生 PDF 文本和页面视觉为依据；第 3、4 册以仓库保留的原页影像为主要依据，重点纠正 OCR 错字。所有文字修改必须能回溯到原书页码。

### 第二轮：内容审核员

内容审核只用于确认修订没有改变作者本意，并标记校稿边界，不对观点进行合规改写、删减或事实修正。检查重点是：校稿是否意外改变立场、否定词、数量、人物、因果关系或语气强度。

## 排版方案

- 每篇保持明确的一级或二级标题；
- 自然段合并由 PDF 固定行宽造成的软换行；
- 原文真正分段、问答切换、列举和独立强调句保留换行；
- 跨页连续句合并，页码注释仍保留用于追溯；
- 第 3、4 册的原页影像继续作为折叠校对附件，不计入正文；
- `SUMMARY.md` 的顺序和标题与校订后的正文一致。

## 修订记录

新增校订说明，注明：

- 作者为李牧之；
- 本次仅做错字、OCR、断行、标点、标题和版式校订；
- 不对原作观点、事实主张和表达立场作修改；
- 扫描册保留原页影像供读者核对。

同时生成机器可读的修订记录，至少包含册号、原页、文件、修改前、修改后和修订类型，便于抽查与回滚。

## 验证标准

- 五册全部 Markdown 均经过检查；
- 每项文字修订均可定位到原书页码；
- Markdown 链接和图片引用零失效；
- 页码覆盖仍为 967 页；
- 第 3、4 册原页影像仍分别为 119 和 188 张；
- 不出现无依据的观点改写、内容删除或新增正文；
- Git 工作区无空白错误，最终提交作者为 `cychai <chaichunyan@msn.com>`。
