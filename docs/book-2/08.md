# 第八部分

## 第一节提高10倍情商

1，当一个人和你不在一个频率上时，就算你说的每一个字都有道理，你与他说话再多也是废话。而且，你说得越有道理，他就越觉得你废话多。我们总想让别人内心强大，其实吧，这事儿不用教，摔得跟头多了，经历得多了，他内心自然就强大了。真正的爱不是把他抱在怀里，而是让他学会走路。不敢生气的是懦夫，不去生气的才是智者。如果你是对的，你没必要发脾气：如果你是错的，你没资格去发脾气。

2，聊天时，多聊别人有的，而不是你拥有的。听到一个消息就随便表露你的情绪，并不会让人引起共情，反而令人觉得情绪化，记住，如果拿捏不好表达什么情绪，没有情绪就是最好的表态。睡觉前突然想说的话，不管多想，都不要去说，第二天早上你会发现，昨晚的想法有多可怕。

3，重要节日群发短信意义不大，可以对重要的人单独发。当两个人互相都不联系时，这段关系便会不了了之。如果很久后突然联系，那多半是来找你借钱的。如果你感觉对方想借钱，而你又不想借他，直接先说明自己目前经济情况很差，这样能节省很多对方跟你虚伪的客套，彼此都节省时间。

4，如果谈恋爱还三天一小吵五天一大吵的，千万别结婚。三观不同，不必强融，啥叫三观？你喜欢看书，他说你就是装文艺，你喜欢吃西餐，他说撸串多划算，这怎么玩？比大龄单身和离婚更可怕的是，跟一个烦的要死，但又离不了的人过几十年，简直是折磨，婚姻不是爱情的坟墓，婚姻是幻想的坟墓。
