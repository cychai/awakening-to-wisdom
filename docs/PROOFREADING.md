# 校订说明

《醒与悟》为李牧之作品。本 GitBook 版本以五册 PDF 原稿为依据进行保守校订。

本次校订仅处理以下内容：

- 纠正可由原页、上下文和固定词语确认的错字及 OCR 误识别；
- 删除中文之间、标点附近和数字量词之间不必要的空格；
- 合并 PDF 固定版面造成的错误断行和跨页断句；
- 依据原页缩进、标题和语义恢复自然段、问答及列表结构；
- 统一目录与正文标题，改善 GitBook 阅读和导航体验。

校订不改写、不删减、不弱化、不评价作者观点，也不对原文进行风格润色。无法可靠确认的原文保持不变。

第三、四册来自扫描页。为便于复核，正文中继续保留可展开的原页影像；全书同时保留原书页码标记，以便逐页对照。
